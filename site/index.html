Domain research for AI agents

Every good .com is taken. Find the ones that aren't.

Ask your AI assistant for 500 name ideas, and DomainScout checks every one of them against the registries - which are free, what they cost and where to buy them.

It runs in Claude, Cursor or any MCP client, on your own machine: hundreds of names in parallel within polite rate limits, DNS first, then the registry itself over RDAP or WHOIS. No account, no API keys, no server in the middle.

Why DomainScout

Hundreds of names at once

Finding a free .com one name at a time is hopeless. Hand over the whole brainstorm - 500 names in one call - and get back the short list that is actually free.

Registry-accurate

Answers come from the registry itself over RDAP or WHOIS, not from a guess based on DNS. A domain bought but never set up still shows as taken.

Runs on your machine

No server in the middle: queries go straight from your computer to DNS, the registries and public price lists, in parallel within limits per registry, so nobody gets flooded.

Prices and where to buy

Standard prices from public price lists and links to nine registrars, sorted by what the first years really cost - promos included.

Premium names caught

Add a registrar API key - Name.com, Cloudflare, Spaceship or Porkbun - and every free-looking name is confirmed, premium names flagged, prices exact.

Works wherever MCP does

Claude Desktop, Claude Code, Cursor and any other MCP client - plus a command line for scripts and quick checks.

How a domain is checked

Each name goes through the cheapest step that can answer for sure, and only moves on when it cannot.

  1. Normalize

    URLs, www, capitals and international names become clean domains. Names without a TLD get .com, .net and .ai - or yours.

  2. DNS

    A domain with nameservers is taken. Fast, free, and it spares the registries.

  3. Registry (RDAP)

    The authoritative answer, with expiry dates, and domains that are about to be deleted.

  4. WHOIS

    For TLDs without RDAP, such as .io or .de - read with care, so a rate-limit notice never passes for "free".

  5. Registrar API optional

    Confirms the name can be bought, flags premium names and gives the exact price.

  6. Prices and links

    Cheapest first, with first-year and renewal prices and any minimum term.

Install

Node 20 or newer. Then add the server to your MCP client and ask about any names.

claude mcp add domainscout -- npx -y @dakaio/domainscout-mcp

One click: download the DomainScout extension and open it; Claude Desktop installs it and lets you set the options. Or add the server to claude_desktop_config.json by hand (Settings → Developer → Edit Config):

{
  "mcpServers": {
    "domainscout": {
      "command": "npx",
      "args": ["-y", "@dakaio/domainscout-mcp"],
      "env": { "DOMAINSCOUT_TLDS": "com,net,ai,io" }
    }
  }
}

On Windows, if npx is not found, use "command": "cmd" with "args": ["/c", "npx", "-y", "@dakaio/domainscout-mcp"].

Add to .cursor/mcp.json in your project, or to the global MCP settings:

{
  "mcpServers": {
    "domainscout": {
      "command": "npx",
      "args": ["-y", "@dakaio/domainscout-mcp"]
    }
  }
}

Settings

All optional, set as environment variables in the MCP config.

VariableDefaultWhat it does
DOMAINSCOUT_TLDScom,net,aiTLDs tried for names given without one
DOMAINSCOUT_REGISTRARSallRegistrars to show buy links for
DOMAINSCOUT_MAX_CONCURRENCY10Network requests in flight at once
DOMAINSCOUT_CONFIRM_MAX50Free domains per call confirmed through your registrar API
DOMAINSCOUT_PRICESonPublic price lists
DOMAINSCOUT_AFFILIATEonAffiliate buy links; off gives plain links

Registrar API keys (Name.com, Cloudflare, Spaceship, Porkbun) and every other setting are described in the README.

Questions and answers

If a domain is not in WHOIS, is it really free?

Almost always. Premium and registry-reserved names look the same in the registry, so DomainScout reports them as likely available, and confirms them when you add a registrar API key.

Is a domain without a website free?

No. A domain that was bought but never set up has no DNS, but the registry still lists it, so DomainScout reports it as taken.

How many names can I check at once?

Up to 500 domains in one call by default - a whole AI brainstorm at once - and DOMAINSCOUT_MAX_DOMAINS raises the limit to 10,000. Names that are already taken are settled in DNS within seconds; only the rest go to the registries, at a polite pace.

Do I need an account or an API key?

No. Everything works without keys. A registrar API key is optional and makes the answer exact for premium names and prices.

Which TLDs can it check?

Any TLD with RDAP or WHOIS, which is nearly all of them. Names without a TLD are tried in .com, .net and .ai unless you set others.

Is DomainScout free?

Yes, open source under the MIT license. Some buy links may be affiliate links: buying through them can support the project at no extra cost to you. Links are always sorted by price, never by commission, and DOMAINSCOUT_AFFILIATE=off turns them off.

Where does my data go?

Straight from your machine to DNS, the registries, two public price lists and, if you add keys, your registrar's API. There is no DomainScout server.

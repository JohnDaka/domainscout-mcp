Privacy Policy

Last updated: October 8, 2026

DomainScout is an open-source MCP server that checks whether domain names are free to register. It runs on your own computer, inside your AI assistant (Claude, Cursor, VS Code or another MCP client). This policy covers the DomainScout server, its Claude Desktop extension and Claude plugin, and this website. It is published by dakaio.com.

What we collect

Nothing. DomainScout has no account, no sign-up, no telemetry, no analytics and no server of its own. We never receive the domain names you check, your conversations with your assistant, or your registrar API keys.

How the server uses your data

To answer a check, the server on your computer sends the domain names you asked about, and nothing else, to the services that know the answer:

  • your DNS resolver, the one your computer already uses, or the DNS servers you set;
  • the registry of each domain's top-level domain, over RDAP, or WHOIS where the registry has no RDAP;
  • IANA, for the public list of which registry serves which top-level domain (a download: no domain names are sent);
  • two public price lists: the Porkbun price API and cfdomainpricing.com, a community mirror of Cloudflare's prices (also downloads, with no domain names); you can turn them off with DOMAINSCOUT_PRICES=off;
  • the APIs of the registrars whose keys you set (Name.com, Cloudflare, Spaceship, Porkbun), only if you set them, to confirm that a free-looking domain is free and get its exact price.

Storage

The server keeps recent answers in memory for a short time, so it doesn't ask the same question twice, and forgets them when it stops. It writes nothing to disk. Registrar API keys stay in your MCP client's settings: Claude Desktop and Claude Code keep keys marked as sensitive in your system's secure storage. Each key is sent only to its own registrar's API.

Third-party sharing

We don't sell, share or receive your data. The services listed above see the requests your computer sends them, as with any website you visit, under their own privacy policies. Buy links take you to a registrar's website; some are affiliate links, which tell the registrar that you came from DomainScout. Affiliate links never change which registrars are shown or their order, and DOMAINSCOUT_AFFILIATE=off turns them off.

Data retention

The server keeps nothing after it stops. This website sets no cookies and runs no analytics. It is served through Cloudflare, and its web server keeps standard access logs (IP address, time, page requested) for security and troubleshooting, which routine log rotation deletes automatically.

Children

DomainScout is a developer tool and is not directed at children under 13.

Changes

If this policy changes, the new version is published on this page with a new date. The history of every change is public in the GitHub repository.

Contact

Questions about privacy: open an issue on GitHub. To report a security problem privately, use the repository's Security tab.
